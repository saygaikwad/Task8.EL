

# Dashboard with Story – Tableau Project

This project contains a Tableau workbook that visualizes key data insights through an interactive dashboard and a story format. The dashboard is designed to present clear, meaningful information through effective visual storytelling.

## File Contents

* `dashboard with story.twb` – Tableau Workbook file containing:

  * A dashboard with interactive visual elements.
  * A story sequence that highlights data insights.


## Project Features

* Interactive charts, graphs, and filters
* Story points guiding the user through the data
* Clean and structured design for easy interpretation

## How to Use

1. Open the `.twb` file in Tableau Desktop or Tableau Public.
2. Navigate between the dashboard and story tabs.
3. Use the filters and other interactive elements to explore the data.
